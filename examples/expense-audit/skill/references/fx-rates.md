# Month-End FX Rates

Finance publishes these on the last business day of each month. They are
the rates the general ledger uses, so the audit must use them too, never
a live rate.

Each rate is **USD per one unit** of the currency.

## 2026-09

| Currency | USD per unit |
| --- | --- |
| USD | 1.000000 |
| EUR | 1.105000 |
| GBP | 1.312500 |
| CAD | 0.724000 |
| JPY | 0.006780 |
